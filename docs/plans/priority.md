# AIAssetStudio — 우선순위 & 로드맵

## 선택한 방식

**직관 정렬** — MVP 기능이 5개라 RICE까지 갈 필요가 없다.

## 우선순위 매트릭스

| 기능 | 핵심가치 | 복잡도 | 1차 MVP |
|-----|--------|-------|-------|
| 1. 프로젝트 프리셋 | Yes — 없으면 "프로젝트마다 같은 화풍·규격"이 성립 안 함 | Easy | ✅ |
| 2. 이미지 에셋 생성 + 후처리 | Yes — 앱의 주 산출물 | Hard (대기열·ComfyUI 연동·픽셀 정리) | ✅ |
| 3. BGM 생성 | Yes — 두 번째 산출물 | Medium (모델 전환·반복 구간 처리) | ✅ |
| 4. MCP 서버 | Yes — 주 사용 방식이 Claude Code | Medium | ✅ |
| 5. 웹 갤러리 | Yes — 최종 선택, 특히 BGM은 사람이 들어야 함 | Medium | ✅ |

다섯 개가 모두 Yes라서 범위가 부풀 위험이 있다. 그래서 각 기능을 최소형으로 묶는다.
- 프로젝트 프리셋은 참고 이미지 1장까지만 받는다.
- 갤러리는 보기·고르기·내보내기만 한다. 생성과 프로젝트 편집은 Claude Code(MCP)로 한다.
- 음악은 연주곡(ACE-Step)을 먼저 만들고, 보컬 곡(YuE2)은 같은 틀에 옵션으로 붙인다.

## 로드맵

### Now (MVP)

1. 프로젝트 프리셋
2. 이미지 에셋 생성 + 후처리 (스프라이트, 아이콘)
3. MCP 서버
4. 웹 갤러리
5. BGM 생성 (연주곡 기본, 보컬 곡 옵션)

### Next (MVP 직후 후보)

- 4방향 시트와 애니메이션 프레임: 참고 이미지 편집이나 LoRA로 프레임 간 일관성 검증부터
- 타일셋, 배경, 초상화
- CLI (같은 HTTP API를 감싸는 얇은 명령어)
- 프로젝트별 LoRA 연결 (ai-toolkit으로 학습한 LoRA를 프리셋에 지정)
- 효과음: 설치된 모델로는 불가. Stable Audio 3 등 모델과 라이선스 검토 필요

### Later (아이디어 저장소)

- 공개 배포 (설치 안내, 모델 다운로드 관리, GPU 사양별 대응, 모델 라이선스 안내)
- LoRA 학습 UI
- 악보(ABC) 편집 UI
- 이미지 부분 편집(인페인팅)
- 엔진별 임포트 자동화 (Unity 임포트 설정 등)
- 갤러리에서 직접 생성하는 전체 UI

## 의존 관계

- ComfyUI 클라이언트 + 작업 대기열 + 저장소 → 모든 기능의 전제
- 프로젝트 프리셋 → 이미지·BGM 생성 (생성 요청이 프리셋을 참조)
- 에셋 API → MCP 도구와 웹 갤러리
- 이미지 파이프라인 → BGM: 검증이 더 많이 된 이미지로 대기열·저장 구조를 먼저 굳히고, 모델 전환 규칙(이미지↔음악)은 BGM 단계에서 붙인다.
