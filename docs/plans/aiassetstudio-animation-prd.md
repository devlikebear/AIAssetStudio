# AIAssetStudio 애니메이션 — PRD (MVP)

_기존 AIAssetStudio에 기능을 더한다. 코드 구조와 컨벤션은 [`codebase-analysis.md`](./codebase-analysis.md)에 있다._

## Overview

LAST LIGHT를 혼자 만드는 개발자가, 스튜디오에서 고른 스프라이트 한 장으로 적 애니메이션을 만든다. 규격은 게임 규약 그대로다(32×32, 발 28번째 줄, 한 줄 10프레임 = 대기 4 + 이동 6).

- 사용자는 Claude Code에서 요청하고, 몇 분 안에 게임 폴더로 내보낸다.
- 지금 게임의 움직임은 기본 포즈 한 장을 코드로 1px 흔들고 발만 좌우로 민 것이라 밋밋하다.
- 생성은 sprite-gen(Apache-2.0) + codex(ChatGPT 구독 이미지 생성)로 한다.
  - 2026-09-25 시험: idle과 정면 걷기가 모두 쓸 만했다.
  - 로컬 Qwen은 대기만 성공했다.
- 기본 그림이 OpenAI로 전송되므로, 프로젝트마다 켜야만 쓴다.

## MVP 기능 목록

| # | 기능명 | 한 줄 설명 | MVP에 필요한 이유 |
|---|-----|---------|--------------|
| 1 | 클라우드 사용 설정 | 프로젝트마다 "애니메이션에 클라우드 사용"을 둔다(기본 꺼짐) | 그림이 외부로 나가는 것을 사용자가 프로젝트 단위로 허락한다(사용자 결정 2026-09-25) |
| 2 | 애니메이션 작업 | 스프라이트 에셋 하나로 sprite-gen(codex)을 돌려 대기 4 + 이동 6 프레임을 만들고, 프로젝트 규격(크기, 발 줄, 색)으로 정리한다 | 기능의 본체 |
| 3 | 축척·일관성 맞추기 | 프레임이 기본 그림과 같은 픽셀 크기와 발 줄에 서게 한다. 벗어나면 표시한다 | 시험에서 프레임이 15% 크게 나왔다. 그대로는 게임에 넣을 수 없다 |
| 4 | Claude Code에서 요청·확인 | MCP `generate_animation`과 `get_job`이 프레임 시트 미리보기와 설명을 돌려준다 | 주 사용 방식이 Claude Code다 |
| 5 | 게임 규약으로 내보내기 | `<이름>.png`(10칸 한 줄), `<이름>/000~009.png`, `<이름>.json`(idle·walk 태그와 프레임 시간) | 손질 없이 게임에 넣는다(사용자 결정 2026-09-25) |
| 6 | 갤러리에서 보기 | 애니메이션 카드(재생), 상세(대기·이동 따로 재생, 프레임), 프로젝트 정보의 클라우드 설정 | 움직임은 사람이 보고 골라야 한다 |

## 유저 스토리 & 수용 기준

### 기능 1: 클라우드 사용 설정

**유저 스토리**
> As a LAST LIGHT 개발자, I want to 애니메이션에 클라우드를 쓸 프로젝트를 직접 켜고 싶다, so that 다른 프로젝트의 그림은 절대 밖으로 나가지 않는다.

**수용 기준**
- Given 새 프로젝트, When 만들면, Then `animation_cloud`는 꺼져 있다.
- Given 꺼진 프로젝트, When 애니메이션을 요청하면, Then 422로 거부하고 "update_project로 animation_cloud를 켜라"고 알린다. 외부로는 아무것도 보내지 않는다.
- Given 기존 `studio.db`(스키마 v1), When 새 백엔드가 열면, Then v2로 올라가고 기존 프로젝트는 모두 꺼진 상태다.
- Given MCP `update_project(animation_cloud=true)`, When 켜면, Then `get_project`와 갤러리 프로젝트 정보에 보인다.

### 기능 2: 애니메이션 작업

**유저 스토리**
> As a LAST LIGHT 개발자, I want to 고른 적 스프라이트 한 장으로 대기·이동 애니메이션 후보를 만들고 싶다, so that 적마다 프레임을 손으로 그리지 않아도 된다.

**수용 기준**
- Given 클라우드를 켠 픽셀 프로젝트의 스프라이트 에셋, When `POST /api/jobs/animation {asset_id}`, Then 작업이 대기열에 들어가 `done`이 되고, 애니메이션 에셋이 생긴다.
- 에셋에는 10프레임이 있다. 모두 프로젝트 크기(32×32)이고, 알파는 0/255이며, 색은 `max_colors` 이하다(고정 팔레트가 있으면 그 색만).
- Given codex 로그인이 없거나 sprite-gen이 없을 때, When 요청하면, Then 작업은 이유를 적고 `failed`가 된다. `studio_status`도 애니메이션이 준비되지 않았다고 알린다.
- Given 애니메이션 작업이 도는 동안, When 이미지 작업이 들어오면, Then 차례를 기다린다.
- 애니메이션 작업은 ComfyUI를 띄우지 않는다. 시작할 때 GPU 모델이 올라가 있으면 먼저 비운다. 몇 분 동안 GPU를 쓰지 않으므로, 기존 "60초 유휴면 해제" 정책과 같게 공유 GPU를 돌려준다.

### 기능 3: 축척·일관성 맞추기

**유저 스토리**
> As a LAST LIGHT 개발자, I want to 애니메이션 프레임이 기본 스프라이트와 같은 크기로 서기를 원한다, so that 게임에서 멈춰 있을 때와 움직일 때 캐릭터 크기가 튀지 않는다.

**수용 기준**
- Given 기본 그림이 17×26칸, When 애니메이션을 만들면, Then 대기 프레임의 높이가 기본 그림과 ±1칸 안이다(아니면 meta와 get_job에 "크기 다름"을 표시한다).
- 모든 프레임의 발은 프로젝트 발 줄에 선다(LAST LIGHT는 28번째 줄, `reference_ground`와 같은 규칙).
- 이동 6프레임이 대기 프레임과 같은 캐릭터로 보인다. 사람이 보고 판단하고, 자동 점검은 sprite-gen `inspect` 결과를 meta에 남긴다.

### 기능 4: Claude Code에서 요청·확인

**유저 스토리**
> As a LAST LIGHT 개발자, I want to Claude Code에 "이 적으로 애니메이션 만들어줘"라고 말하고 싶다, so that 에셋 흐름을 벗어나지 않는다.

**수용 기준**
- Given MCP, When `generate_animation(asset_id, count=1)`, Then 작업 id를 바로 돌려주고, 도구 설명에 "기본 그림을 OpenAI로 보낸다"가 있다.
- Given 끝난 작업, When `get_job`, Then 후보마다 10프레임을 한 줄로 이은 미리보기 PNG와 설명(프레임 크기, 발 줄, 경고, 클라우드 사용)을 돌려준다.
- Given `studio_status`, When 부르면, Then "animation (sprite-gen + codex): ready" 또는 준비되지 않은 이유를 보인다.

### 기능 5: 게임 규약으로 내보내기

**유저 스토리**
> As a LAST LIGHT 개발자, I want to 고른 애니메이션을 게임이 쓰는 형식 그대로 받고 싶다, so that 변환 스크립트 없이 `ArtSource`/`CampaignArt`에 넣는다.

**수용 기준**
- Given 애니메이션 에셋, When `export_asset(asset_id, name="shadow_walker")`, Then `shadow_walker.png`(320×32), `shadow_walker/000.png`~`009.png`, `shadow_walker.json`이 생긴다.
- JSON 내용: 프레임 크기, `idle` 0~3번(각 0.18초), `walk` 4~9번(각 0.1초). `Tools/archive_campaign_art.lua`의 태그와 시간과 같다.
- 이미 있는 이름이면 덮어쓰지 않고 `_2`를 붙인다. 세 가지 모두 같은 이름으로 붙는다.

### 기능 6: 갤러리에서 보기

**유저 스토리**
> As a LAST LIGHT 개발자, I want to 갤러리에서 애니메이션이 실제로 움직이는 걸 보고 고르고 싶다, so that 이상한 프레임이 섞인 후보를 걸러낸다.

**수용 기준**
- Given 애니메이션 작업, When 갤러리를 열면, Then 카드에서 대기·이동이 이어 재생된다(정수배 확대, 발 줄 표시).
- Given 상세 화면, When 열면, Then 대기와 이동을 따로 재생하고, 10프레임을 나란히 보고, 고르기·버리기·내보내기를 할 수 있다.
- Given 프로젝트 정보, When 열면, Then "애니메이션에 클라우드 사용: 켬/끔"이 보인다.

## Out of Scope (MVP에서 명시적으로 뺀 것)

- **주인공 4방향** — 뺀 이유: 방향마다 기준 그림이 필요하고 아직 시험하지 않았다. 재검토 시점: MVP 사용 뒤(다음 확장 1순위)
- **공격 등 다른 상태** — 뺀 이유: 게임에 공격 프레임 규약이 없다. codex 시험은 성공했다. 재검토 시점: 게임에서 필요해질 때
- **로컬(Qwen) 생성** — 뺀 이유: 대기만 성공하고 이동은 실패했다. 재검토 시점: 더 나은 로컬 모델이 생길 때
- **Grok 이미지·영상 경로** — 뺀 이유: 로그인이 없다. codex로 충분하다
- **별도 클라우드 대기열**(GPU 작업과 동시 실행) — 뺀 이유: 혼자 쓰면 같은 대기열로 충분하다. 재검토 시점: 기다림이 불편해질 때
- **갤러리에서 애니메이션 만들기 버튼** — 뺀 이유: 주 사용 방식이 MCP다
- **보스 48×48 보장** — 프로젝트 규격을 그대로 쓰므로 동작은 할 수 있지만 시험하지 않는다
- **Aseprite 파일 직접 만들기** — 게임 쪽 `archive_campaign_art.lua`가 PNG로 만든다

## 의존성

- **외부 도구**: sprite-gen 2.9.0(`<sprite-gen 경로>`, 전용 `.venv`, subprocess로 부름). codex CLI 0.155 이상(Codex 앱에 든 것. PATH의 0.147은 새 설정을 못 읽음)
- **외부 서비스**: OpenAI(ChatGPT 구독의 이미지 생성, 호출당 과금 없음, 구독 한도 있음). 한 줄에 60~90초
- **인증/권한**: codex에 ChatGPT로 로그인해야 한다(사용자가 직접). Plus 이상, 이미지 생성 포함
- **플랫폼**: Windows, 이 PC

## 비기능 요구사항

- **성능**: 애니메이션 작업 하나(대기 + 이동 2줄)는 5분 안에 끝난다(시험: 2~3줄 동시 실행 87초)
- **보안/개인정보**: 클라우드 설정이 꺼진 프로젝트는 어떤 경우에도 외부로 보내지 않는다. 보내는 것은 기본 그림(확대본), 배치 가이드, 프롬프트뿐이다. 에셋 meta에 `cloud: {provider: "codex"}`를 남긴다
- **호환성·데이터 보존·접근성**: 해당 없음(기존과 같음). DB 마이그레이션은 기존 데이터를 지우지 않는다
