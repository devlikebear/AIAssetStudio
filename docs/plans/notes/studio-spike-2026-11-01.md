# Studio 시험 제작 기록 (2026-11-01)

Studio 로드맵의 근거다. 장편 12화를 12쪽 그림책, 오디오북, 움직이는 그림책으로 만들어 봤다. 환경은 Windows 11, RTX 4090 Laptop 16GB, RAM 32GB, ComfyUI 0.37.0이다. 작품 내용과 대본은 이 저장소에 넣지 않는다.

시험 스크립트(작품 내용 없음)는 `spikes/studio/`로 옮긴다(T1.A.1).

## 그림책

- 구성: Qwen-Image-2.1 int8 + Viggle Turbo 6스텝, 1184×880. 투명 스프라이트로 만든 인물 시트 1~2장을 latent 참조로 넣었다.
- 2번째 참조는 `images.image_2`에 넣는다. 첫 참조와 같은 `LoadImage` + `JoinImageWithAlpha` 구성이다. `QwenImage21Cache`(CPU)를 켰다.
- 19장 평균 27.7초(21.3~30.7초). 메모리 부족 없음.
- 닮은 두 인물을 같은 얼굴로 그릴 만큼 인물 일관성은 충분했다.
- 첫 시도 채택 5/12. 프롬프트 수정 1회로 6쪽을 고쳤고 1쪽의 결함은 남았다.

| 실패 | 쪽 수 | 해결 |
|---|---|---|
| 참조 인물이 복제됨 | 1 | 인원수 명시, 조연은 등을 돌리게 함 |
| 조연이 참조 얼굴을 닮음 | 1 | 조연을 멀리 두고 외형을 명시 |
| 자세 때문에 인물 특징이 안 보임 | 1 | 특징이 보이는 쪽으로 구도 지정 |
| 장소가 쪽마다 다름 | 3 | 장소 구조를 프롬프트에 반복 |
| 소품이 원작과 다름 | 3 | 소품을 크게 보이게 지정 |
| 작은 표식의 색이 틀림 | 1 | 2회 시도에도 실패, 부분 재생성 필요 |

- 쪽 본문을 회차 요약으로 쓰면 원문에 없는 내용이 섞인다. 쪽마다 근거 원문과 작가 승인이 필요하다.

## 오디오북

- Qwen3-TTS 1.7B CustomVoice(Apache 2.0), 패키지 `qwen-tts` 0.1.1, Python 3.12.
- 첫 설치에서 `qwen-tts`가 CUDA torch를 CPU판 2.15로 덮었다. torch를 지우고 cu130 인덱스에서 다시 설치해 해결했다.
- `flash-attn` 없이 `attn_implementation="sdpa"`로 동작한다. 모델 로드 92초(첫 다운로드 포함).
- 12쪽 170초 분량을 약 5분에 생성했다. VRAM 최대 4.4GB.
- 한국어 프리셋은 Sohee(여성)뿐이다. 다른 프리셋도 `language="Korean"`으로 말하지만 억양은 사람이 들어 판단해야 한다.
- Whisper 대조 글자 오차 평균 6.9%. 받아쓰기 쪽 오류가 섞여 실제보다 높다. 성과 호칭을 띄어 쓴 표현이 다른 소리로 들렸고, 붙여 쓰니 대부분 바로잡혔다.
- 한 번 Whisper가 무너진 짧은 대사는 재생성하니 정상이었다.
- **사람이 들어본 검증은 아직 없다.**

## 움직이는 그림책

- Wan 2.2 14B I2V fp8 + lightx2v 4스텝 LoRA(Apache 2.0), 파일 합계 37.8GB. ComfyUI 0.37.0 그대로 동작한다.
- 832×624, 81프레임, 16fps. 클립당 평균 193초(182~238초). RAM 여유 최저 1.83GB, VRAM 여유 최저 1.32GB. 멈춤 없음.
- 그래프: 고노이즈 0~2스텝, 저노이즈 2스텝~끝, 둘 다 euler·simple, CFG 1, `ModelSamplingSD3` shift 5.
- **CFG 1이라 부정 프롬프트가 듣지 않는다.** 제자리 지시는 본문 프롬프트에 넣어야 한다.
- 화풍은 잘 유지된다.
- 5초 전체 사용 6/12. 3쪽은 앞 2초만 썼다. 3쪽은 원본 그림 확대로 대체했다.

| 문제 | 쪽 수 | 처리 |
|---|---|---|
| 인물이 카메라로 다가오거나 자세가 크게 바뀜 | 3 | 앞 2초만 왕복 재생 |
| 인물의 작은 외형 특징이 사라짐 | 2 | 원본 그림 확대 |
| 없던 인물이 등장 | 1 | 원본 그림 확대 |

- 왕복 재생에서 물이 거꾸로 흐를 수 있다. 재생 확인 전이다.
- 프레임 수를 쪽별로 반올림하면 싱크가 최대 0.3초 밀린다. 누적 시간 기준으로 프레임 수를 계산해 해결했다.
- ffmpeg 9.0은 `-vsync`가 없다. `-fps_mode`를 쓴다.
