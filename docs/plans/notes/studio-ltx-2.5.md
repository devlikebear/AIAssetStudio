# LTX-2.5와 Wan 2.2 비교 (2026-11-03)

스크립트: `spikes/studio/ltx_compare.py`. 같은 책에서 채택된 그림과 움직임 지시 5쪽을 LTX-2.5로 만들어 Wan 2.2 클립과 나란히 봤다. Wan에서 빈 공간으로 낯선 사람이 들어온 3쪽, 4쪽, 11쪽과 물이 나오는 1쪽, 12쪽이다. 환경은 Windows 11, RTX 4090 Laptop 16GB, RAM 32GB, ComfyUI 0.37.0이다.

## 구성

- `Lightricks/LTX-2.5` 리비전 `49b093a39c19169a8a81721dcc541e07e945232f`. 클릭 동의형 게이트라 사용자 계정의 동의와 토큰이 필요하다. 라이선스는 LTX-2.x 커뮤니티 라이선스(지역 제외 없음, 연매출 1천만 달러 미만 무료).
- 파일 5개, 37.0GB: 22B 증류 영상 모델 int8 20.03GB, Gemma 4 12B 텍스트 인코더 int8 14.32GB, 영상 VAE 1.37GB, 음성 VAE 0.34GB, 공간 업스케일러 0.93GB.
- 그래프는 ComfyUI 내장 템플릿 `video_ltx2_5_i2v.json`을 따른다. 절반 크기에서 8단계, 잠재 공간 2배 업스케일, 3단계. 프롬프트 자동 보강은 껐다. 영상과 음성을 함께 다루는 모델이라 빈 음성 잠재를 같이 넣지만 음성은 버린다.
- 1024×768, 24fps, 121프레임(5초). Wan은 832×624, 16fps, 81프레임이다.
- Wan처럼 텍스트 인코딩을 별도 프롬프트로 먼저 끝내고 내린다.

## 결과

| 쪽 | Wan 2.2 | LTX-2.5 |
|---|---|---|
| 1 | 안정 | 안정, 인물 자세가 조금 변함 |
| 3 | 1.5초부터 낯선 사람 등장 | 인물 추가 없음 |
| 4 | 1.5초부터 낯선 사람 둘 등장 | 인물 추가 없음 |
| 11 | 1.5초부터 낯선 사람 여럿 등장 | 인물 추가 없음 |
| 12 | 안정 | 안정 |

- 생성 시간: 클립당 79~88초, 인코딩 8~17초. Wan은 약 180초였다.
- 메모리: RAM 여유 최저 1.74GB, VRAM 여유 최저 0.52GB, 커밋 여유 최저 0.1GB(한도는 57.6GB까지 늘어남). 5개 모두 오류 없이 끝났다.
- 정지 프레임으로 본 움직임은 Wan보다 작다. 움직임이 충분한지는 사람이 재생해 판단해야 한다.
